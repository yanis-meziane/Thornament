# Thornament 

## Présentation

Dans le cadre de la start-up week, nous avons créer *Thornament*. Cette startup a pour objectif de créer un système de tournois, de ligue et de championnat hyper facilement et pour n'importe quel domaine. 


## Installation 

1. *Clônage du projet*  

Dans votre terminal, dans un dossier que vous créez intitulé 'Startup Week', vous pourrez faire un git clone de notre projet. 

```git 
git clone https://github.com/yanis-meziane/Thornament.git
```

2. *Installation des dépendances* 

